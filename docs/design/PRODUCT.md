# PRODUCT

## 项目定位

茂一杀是一款校园恶搞主题的三国杀式联机卡牌游戏，保留 React/Vite、Photon、CloudBase、Electron、Capacitor 架构。目标是让 PC 与 Android 横屏玩家都能快速进入房间、清楚读懂牌桌状态、稳定完成出牌/响应/弃牌，并在断线或异常退出后安全恢复。

## 用户

- Windows PC 玩家：完整桌面窗口，大厅、房间、标准牌局、狼人杀、练习场、设置。
- Android 横屏玩家：触控操作，按钮目标不小于 44px，安全区不遮挡 HUD 与手牌。
- 管理/发布者：需要完整 Windows ZIP、签名 APK、七牛差异清单和 SHA-256。

## 1.4.5 产品方向

- 对局表现保持克制牌桌演出：飞牌、斩击、火/雷、治疗、锦囊、封印、阶段牌匾、落败印章。
- 手牌保持纸牌式窄长卡，并提升禁用/响应状态下的可读性。
- 玩家牌框继续向竖向角色牌方向收敛，姓名、身份、体力点、手牌数、装备/判定状态更集中。
- 多人局排布以 8 人局清晰为基准，避免右侧玩家和本方牌压叠。
- Windows 端支持键盘出牌，设置中可改键位。
- Windows 本机可选择加密记住邮箱和密码；浏览器/Android 不保存密码。
- 联机诊断记录本机重连次数、成功次数、成功率和平均耗时，便于后续统计真实断联问题。
- 大厅保持固定一屏主菜单；模式入口和底部导航减少钝角圆，使用棱形、六边形、斜切牌匾。
- 所有表现层改动不修改规则、Photon 协议、CloudBase 数据或存档。

## 反向约束

- 不复制商业游戏素材、图标、卡框或具体 UI，只参考“玩法优先、HUD 不遮挡、信息少常驻”的原则。
- 不做全屏高频特效、持续震屏或长时间遮挡牌桌中心。
- 不通过七牛发布 React/CSS/Electron/Android 代码；UI 代码改动必须发完整 Windows ZIP 和 APK。

## 成功标准

- 1120×720、1360×860、1920×1080 大厅无页面滚动条。
- 4/6/8 人标准局顶部玩家完整可见，HUD 不压头像、姓名、体力。
- 8 人局右侧座位无明显压叠。
- 桌面手牌区高度约 158–186px；Android 横屏目标 118–140px。
- `off/low/normal/high/reduceMotion` 特效设置可用。
- 键盘可完成选牌、选目标、确认、取消、结束回合、手动重连和打开菜单。
