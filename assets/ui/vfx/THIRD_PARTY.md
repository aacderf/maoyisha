# Third-party VFX assets

The sprite atlases in this directory were rendered from the official Effekseer
sample library and are distributed under CC0 1.0.

- Effekseer tutorial `05_02_Sample`: slash impact.
- NextSoft `NextSoft01`: fire, thunder, heal, shield and power-up effects.
- Broken Desk `MAGICALxSPIRAL`: magic area, attack impact and breakdown effects.
- tktk `tktk01`: dark effect used with a green poison tint.
- HATO `HATO-Springhascome`: sakura cursor trail source.
- Effekseer WebGL sample texture `Particle01.png`: particle cursor trail source.
- tktk `smoke_tex.png`: ink-wash cursor/card-flight trail texture.

The `guofeng-*` atlases are Maoyisha tint/composite passes of the same CC0
Effekseer source frames, using warmer gold/red/ink palettes for San Guo
Sha-style card combat feedback.
