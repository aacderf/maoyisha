# Cursor assets

Cursor PNG frames are converted from user-provided local cursor packs under
the sibling material folder `D:\AI\card-game-materials\cursor` (original folder
name is Chinese on the local machine).

Included selectable themes:

- `silksong`
- `luoxiaohei`
- `silverwolf`
- `firefly`
- `classicPointer`

The game uses DOM-rendered PNG frames instead of native `.cur` / `.ani` cursor
URLs so Chromium can reliably render large and animated cursor themes.
